# Euphoria

**Worlds without limits.**

Euphoria is an open platform for creating, publishing, and playing games on the web.

The project brings together a game engine, a platform for creators and players, and the infrastructure needed to run multiplayer experiences.

## Features

- **Web-based gaming** — Create and play games directly in the browser, with no downloads or installations required.
- **Game creation** — Build interactive 2D and 3D experiences using a modern development environment.
- **Multiplayer** — Create shared experiences with real-time communication and multiplayer support.
- **Publishing** — Publish games and make them accessible to players through a common platform.
- **Discovery** — Explore games, find new experiences, and connect with creators.
- **Creator-focused** — Tools and services designed to support the entire process, from development to distribution.
- **Open ecosystem** — Build with Euphoria or integrate its tools and technology into your own projects.
